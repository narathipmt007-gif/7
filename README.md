## การอ้างอิงพระเคราะห์เสวยอายุ/แทรก
แหล่งหลักตามคำขอ: https://www.mahamongkol.com/m/content.php?id=229
หน้าอ้างอิงนี้เป็นหมวดคนเกิดวันพุธกลางวัน (06:01–18:00) จึงฝังข้อมูลสรุปเฉพาะช่วงอายุและชื่อดาวของหมวดนี้ไว้สำหรับค้นหาอายุ ไม่ได้คัดลอกคำพยากรณ์ฉบับเต็ม
สำหรับวันเกิดหมวดอื่น โปรแกรมมีลิงก์ไปยังหน้าต้นฉบับของมหามงคลให้ตรวจสอบโดยตรง

## สูตรกำลังดาว 108
ตามภาพผู้ใช้: อาทิตย์ 6, จันทร์ 15, อังคาร 8, พุธ 17, เสาร์ 10, พฤหัสบดี 19, ราหู 12, ศุกร์ 21 (รวม 108)
- ปีเสวย = กำลังดาวเสวย × กำลังดาวตัวเอง ÷ 108
- เดือนแทรก = กำลังดาวเสวย × กำลังดาวแทรก ÷ 108
สูตรนี้แยกจากตารางช่วงอายุของมหามงคล ไม่ได้ใช้แทนกันอัตโนมัติ

## ข้อจำกัด
- โปรแกรมตั้งเวลาเปลี่ยนวันเป็น 00:00 น. ตามคำขอ ส่วนเว็บไซต์อ้างอิงแบ่งหมวดพุธกลางวัน 06:01–18:00 และพุธกลางคืน 18:01–06:00
- ตารางอายุที่ฝังในตัวโปรแกรมเป็นสรุปสำหรับพุธกลางวันเท่านั้น ช่วงอายุที่ไม่อยู่ในรายการให้เปิดต้นฉบับตรวจสอบ
